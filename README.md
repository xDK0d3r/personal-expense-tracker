# Personal Expense Tracker

A lightweight personal expense tracker built with Python and SQLite.

## 📖 Overview

Personal Expense Tracker is a command-line application for managing personal expenses.

This project is built as a **learning project**, with a focus on applying Python Object-Oriented Programming, SQL, and SQLite in a practical application.

## ✨ Features

- Add, view, edit, and delete expenses
- Categorize expenses
- Store expense dates and amounts
- Persistent data storage with SQLite
- Expense summaries and analysis

## 🛠️ Tech Stack

- Python
- SQLite
- SQL
